## 📖 Sobre el proyecto

Juego de fiesta multijugador local: todos ven la palabra secreta menos el impostor, que tiene que disimular. Se pasa un solo teléfono de mano en mano, se discute y se vota.

## ✨ Qué hace

- Se juega con un solo dispositivo, pasándolo entre jugadores
- Fases completas: reparto, discusión, votación y revelación
- Categorías de palabras y ajustes de partida
- Háptica, animaciones Lottie y pantalla siempre encendida
- Expo Router · MIT · guía de contribución incluida

## 🚀 Empezar

```bash
git clone https://github.com/Harkor421/el-impostor-party.git
cd el-impostor-party
yarn install
yarn run start
```

## 📜 Scripts

| Comando | Qué hace |
|---|---|
| `yarn run start` | Arranca la aplicación |
| `yarn run android` | Corre la app en el emulador de Android |
| `yarn run ios` | Corre la app en el simulador de iOS |
| `yarn run web` | Corre la app en el navegador |
